Status: local draft only. No remote PR has been created. Proposed base: master at `0af1f2cc15b91691eeb30c7ec65b9ae07ee137f1` (reverified 24 October 2026).

## Summary

- Add a bounded rich web package runtime with local textures, full geometry, vectors, authored controls, readouts, picking, user-initiated audio and responsive layout.
- Convert all 26 existing Explorations into genuine independently buildable, versioned packages. Preserve original artwork, models, investigations and scientific caveats; retain native bundled originals.
- Restore Castle's package-owned non-WebGL fallback. Group downloaded alternatives beside accessible original catalog entries without redirecting existing bookmarks.
- Preserve explicit child version grants, revocation, household isolation and fail-closed online authorization. No automatic production import or child migration.
- Include detailed per-topic plans, authoring guide, generated examples, security/education regression tests and actual desktop/mobile comparison evidence.

## Review focus

Review the generic sandbox/parser resource bounds, archive budget change, immutable payload lifecycle, catalog access filtering, independent source ownership and all 26 authored educational interactions. ## Scope exclusions

No deployment, production package import, child grant, APK build, Android version/build change or merge is included. The separate Android release branch/PR is unaffected. Native downloaded playback remains unsupported. Browser workers have no hard heap quota; bounds and watchdogs mitigate but do not eliminate memory-pressure risk.

## Operator choice

After code review and separate publication/deployment authorization, upgrade web runtime, pilot packages in a test household, then import/review/publish chosen versions and approve each child explicitly. Rollback also requires fresh approval. Existing original routes remain untouched.
